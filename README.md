# Costra

AI Cost Intelligence for the enterprise.

**See every AI cost. Know who owns it. Find the savings.**

## MVP

Costra is a polished Next.js prototype for an enterprise AI FinOps platform. It includes spend visibility, business-unit allocation, an AI spend trend, optimization opportunities, provider landscape, governance signals, search, navigation, and interactive detail drawers.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Next steps

Connect real cloud/model billing sources, persist the enterprise hierarchy, and replace the prototype data with the Costra allocation, cost, intelligence, and optimization engines.
